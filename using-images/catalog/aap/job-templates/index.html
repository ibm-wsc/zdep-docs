#Job Templates — Ansible Automation Platform (AAP) for z/OS

All job templates below are pre-loaded in the AAP z/OS inventory, use the aap4zos EE execution environment, and target zos_host with the z/OS Host SSH Key credential.

#z/OS Admin

  • z/OS Gather Facts — Collects z/OS system information (system name, sysplex, version, IPL info) using the zos_gather_facts module. Good first job to run to verify end-to-end connectivity.
  • z/OS TSO Command(s) — Executes one or more TSO commands on the z/OS host and displays the output. Survey prompts for the command(s) to run.
  • z/OS WTOR Query — Queries the operator console for outstanding WTOR (Write To Operator with Reply) messages awaiting a response.
  • z/OS Password Reset — Resets a RACF user's password via TSO commands and generates a temporary one. The user must change it on next login.

#APF Authorization

  • z/OS APF - List — Lists all currently APF-authorized libraries on the z/OS system.
  • z/OS APF - Authorize — Dynamically APF-authorizes a load library. Authorization does not persist across IPL on this image.
  • z/OS APF - Deauthorize — Removes a library from the dynamic APF list.

#Data Sets

  • z/OS Data Set - Basics — Walks through a sequence of basic data set operations: create, write, copy, list members, and delete.
  • z/OS Data Set - Create — Creates a z/OS data set with a name, type, record format, and size of your choosing via survey.
  • z/OS Data Set - Delete — Deletes a named z/OS data set via survey.

#Jobs / JCL

  • z/OS Submit JCL — Submits a sample JCL job from the aap4zos project to the z/OS host, waits for completion, and displays the output. Survey lets you choose between HELLO, ALLOCATE_PDS, or INVALID_JCL.

#Operator

  • z/OS Operator Command — Executes a z/OS operator command and returns the console output. Survey prompts for the command and wait time.

#Certificate Management

  • z/OS Keyring - Create — Creates a RACF keyring for a specified user using TSO commands.
  • z/OS Certificate - Create — Creates a SITE, USER, or CERTAUTH certificate — self-signed or signed by a local CA.
  • z/OS Certificate - Delete — Deletes a named certificate from RACF.
  • z/OS Certificate - List — Displays details of a named certificate.
