#z/OS Standard + CICS

The z/OS Standard + CICS image is a pre-configured z/OS environment with CICS Transaction Server 6.2. It is configured with sample programs, transactions, VSAM files, and Java bundles, and is ready for CICS-based demonstrations immediately after provisioning from TechZone.

#What's Included

  • z/OS 3.1 — See Base z/OS Configuration for the full system layout
  • CICS Transaction Server 6.2 — Configured with CICSPlex SM (CMCI)
  • Sample COBOL program — HELLO program / HELO transaction
  • Java bundles — TERMINAL and VSAM OSGi bundles deployed via CMCI
  • VSAM files — ZOSADMN.TEST.KSDS.STOCK, ZOSADMN.TEST.ESDS.STOCK, and ZOSADMN.TEST.RRDS.STOCK pre-defined and accessible
  • SSL/TLS security — Keyring CICSRING with self-signed certificates
  • CICS-only non-admin userids - Userids CICSU01, CICSU02, and CICSU03 are provided to demonstrate principles of "least privilege" - these userids cannot log on to TSO and they cannot execute CICS administrative transactions. They are permitted to run the sample CICS transactions provided on this image- HELO, JTM1, JVK1-5, JVE1-5, and JVR1-5. Check with the image owner for the password, or you can reset the password for these userids yourself with the ZOSADMN userid.

#Quick Start

For VPN, SSH, and 3270 terminal setup, see Connecting to Your Instance.

Once connected, follow these steps to verify that CICS is working:

  1. Connect via 3270 emulator to port 2023
  2. Connect to CICS: logon applids(CICSTS1)
  3. Log on to CICS with userid ZOSADMN and the password you set for ZOSADMN. Alternatively, log in with one of the CICS-only non-admin userids- CICSU01, CICSU02, or CICSU03.
  4. Enter: HELO — the Hello World message from the HELLO COBOL program appears
  5. Enter: JTM1 and any number of optional arguments - any arguments you enter after 'JTM1' will be parsed into separate space-delimited parameters and shown on the screen
  6. To run sample transactions that work with VSAM Key-sequenced data sets: enter, in order, JVK1, JVK2, JVK3, JVK4, and JVK5.
  7. To run sample transactions that work with VSAM Entry-sequenced data sets: enter, in order, JVE1, JVE2, JVE3, JVE4, and JVE5.
  8. To run sample transactions that work with VSAM Relative-record data sets: enter, in order, JVR1, JVR2, JVR3, JVR4, and JVR5.
  9. To demonstrate least privilege, if you are logged in with one of the CICS-only non-admin userids, try to enter a CICS administrative transaction such as CEMT or CEDA. You will get a message indicating that you are not authorized to run the transaction.
