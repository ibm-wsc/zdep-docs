#z/OS Standard + Db2

The z/OS Standard + Db2 image is a pre-configured z/OS 3.1 environment with IBM Db2 for z/OS Version 13 installed and configured. It is built on top of the z/OS Standard Image and is available on TechZone for Db2 demonstrations, application development, and integration testing.

#What's Included

  • z/OS 3.1 — See Base z/OS Configuration for the full system layout
  • Db2 for z/OS Version 13 — Installed, configured, and ready to use after provisioning
  • JDBC connectivity — JCC drivers bound and accessible via TCP/IP
  • RACF security — Db2 SYSADM, security, and started-task profiles pre-configured
  • RRS (Resource Recovery Services) — Configured and auto-started for Db2 unit-of-recovery support

For the full product list including FMIDs, see Installed Products.
